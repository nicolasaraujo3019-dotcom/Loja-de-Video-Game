GameHub – Loja Virtual de Videogames
Versão: 1.0 Data: 22/06/2026 Autor: Projeto Acadêmico / Desenvolvimento Web Status: Em desenvolvimento
 Sobre o Projeto
O GameHub é um sistema web de e-commerce especializado na comercialização de consoles, jogos, acessórios e peças para videogames. O objetivo é oferecer uma plataforma intuitiva, responsiva e funcional, que atenda tanto aos clientes quanto aos responsáveis pela gestão da loja.
Este projeto foi desenvolvido como trabalho acadêmico, aplicando conceitos de análise de requisitos, modelagem de sistemas, normalização de dados, padronização de código e boas práticas de desenvolvimento.
 Principais Funcionalidades
✅ Navegação por categorias e busca de produtos
✅ Cadastro e autenticação de usuários com níveis de acesso
✅ Carrinho de compras temporário
✅ Cálculo automático de frete por CEP
✅ Finalização de pedidos e escolha de forma de pagamento
✅ Acompanhamento e rastreamento de pedidos
✅ Área administrativa para gerenciar produtos, categorias e pedidos
✅ Interface responsiva para desktop e dispositivos móveis

 Modelagem e Organização
Modelo Conceitual: Definição das entidades e regras do negócio
Diagrama de Classes: Representação das estruturas e comportamentos
Diagrama de Relacionamentos: Ligação entre entidades, aplicando normalização de dados até a 3ª Forma Normal
Padronização: Nomenclatura consistente, tipos de dados definidos e comentários explicativos
 Motivo das Escolhas Técnicas
HTML5, CSS3 e JavaScript: Tecnologias amplamente utilizadas, compatíveis com todos os navegadores e ideais para um projeto de interface web, sem necessidade de configurações complexas.
Arquitetura simples: Prioriza a clareza e facilidade de manutenção, permitindo que qualquer pessoa entenda e altere o código rapidamente.
Normalização de dados: Evita redundâncias, garante consistência e prepara o sistema para futura integração com banco de dados.
GitHub Pages: Permite hospedar e acessar o projeto de forma gratuita e prática, sem custos com servidores.
Responsividade: Atende ao requisito de funcionamento em diferentes tamanhos de tela, melhorando a experiência do usuário.
